## 🚀 Getting Started

### Option 1: View Locally
1. Download all files to a folder
2. Open `index.html` in your web browser
3. Navigate between pages using the menu

### Option 2: Deploy to Web Hosting
1. Upload all files to your web hosting service (cPanel, FTP, etc.)
2. Make sure all files are in the same directory
3. Your website will be live at your domain!

### Option 3: Deploy to GitHub Pages
1. Create a new GitHub repository
2. Upload all files
3. Go to Settings → Pages
4. Select "main" branch and save
5. Your site will be live at `username.github.io/repository-name`

## 🎨 Customizing Styles

All styles are in `styles.css`. To change colors, fonts, or spacing:

1. Open `styles.css`
2. Find the CSS variable at the top (`:root` section)
3. Change the values
4. Save and refresh

Example:
```css
:root {
  --crimson-red: #9E1B32;  /* Change this color */
  --rich-gold: #C9A24A;    /* Change this color */
}
```
